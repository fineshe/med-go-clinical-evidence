# 分学科指南参考库

供临床路径查找候选指南，再核对官方原文。整理于 2026-10-19；不是已经核验有效性的推荐知识库，不能依据此目录直接生成治疗建议。

## 按需读取

- 快速选学科及常见主题：[40 学科候选导航](specialty-index.md)。这是起步清单，不是全学科完整必读目录。
- 程序读取候选清单：[specialty-shortlist.json](specialty-shortlist.json)。含题名、机构、类型、年份、链接、选入依据和 Excel 溯源。
- 详细查找：[catalog.jsonl](catalog.jsonl)。**不要整份加载到对话**；用下方脚本按学科/关键词定位，必要时再读单条原始来源。
- [统计与输入文件校验值](catalog-summary.json)、[缺题名的 507 条线索](incomplete-records.jsonl)。后者只有文件名/docId 等，不能视为已取得 PDF 或正式题名。
- 官方机构补查：[机构入口与二次证据](../guideline-sources.md)。它不是机构质量排名，相关性由问题决定。

```text
python scripts/find_guidelines.py --list-specialties
python scripts/find_guidelines.py --specialty "本次学科" --query "本次关键词" --limit 10
python scripts/find_guidelines.py --query "关键词一" --query "关键词二"
```

重复 `--query` 是字面子串 AND，不解析数据库布尔式。中英文同义词分别运行，再合并 ID。`--include-other` 才显示译本、更正、评论等其他记录，默认显示指南/推荐/共识且分别标类型。结果先按指南、推荐、共识类型分组，再按表内年份降序，**不代表证据质量排序**。无命中时换同义词或外部检索，不得推断没有指南。无 Python 时可用文本检索 JSONL。

## 实际来源与统计口径

来源一《指南2026最新汇总.xlsx》有 17,630 条非空行：17,123 条有题名，507 条只有 docId/文件名等。来源二《指南list(1).xlsx》有 645 条非空题录，含 ACOG、SOGC、RCOG、ISUOG、FIGO、NICE、SMFM、JSOG、RANZCOG、WHO、中华医学会共 11 张表。中华医学会表首行即题录，未丢作表头；WHO/RANZCOG 的 345 条空白行未计入。

合计 18,275 条非空行，其中有题名的 17,768 条保守去重后为 16,538 条；合并了 1,230 条重复行，各来源位置仍保留。使用一致 DOI、PMID 或相同题名+年份，文件类型/标识冲突时保留独立记录。此去重不等于已识别所有同一指南的不同语言、摘要、全文、更新和译本。

自动题录分类：指南候选 6,048；推荐/规范候选 1,215；共识/立场声明 7,657；解读/评论/研究等 646；译本 20；更正/撤回 12；其他/待核实 940。**分类依据题名及原表标签，可能误分，使用前仍核对文献类型。** 标识/类型冲突记录 62 条，未强行合并。14,258 条带原表链接或由 DOI/PMID 生成的入口，2,280 条无直接链接；有 URL 不表示已验证链接或全文。

学科同义词归一，多学科标签保留；题录索引有 45 种归一标签（包括综合/待分类、非医学等），本次导航选择 40 个临床/相关学科，不把两种数字混用。原表 WHO 的 OB 标签不能代表全部内容属于妇产科，按题名推定学科并标明待核实。机构名来自工作表时也注明推定依据。

## 使用一条题录前

1. 核对中英文题名是否指同一文件、DOI/PMID 是否匹配、是正式指南还是共识/摘要/译本/更正。原表字段可能错配，标识冲突先处理。
2. 打开官方机构或原出版方，确认正式发布机构、最新/被替代/撤回状态、版本号及更新日期。年份字段是原表日期抽取，可能和题名版本年不同；保留两者，不擅自改写。
3. 阅读与本次问题直接相关的推荐、适用人群、证据截止日、原有推荐强度和证据确定性，记录原文定位与读取层级。
4. 之后查系统综述/Meta 等二次研究，再按缺口查原始研究。目录没有收录与全文不可访问是不同状态。

全部 `current_status=not_verified`，`retrieval_level=catalog_metadata_only`。本次没有逐篇更新验证、原文推荐提取或临床专家审核；不把文件名“2026最新”传递为每条的有效状态。

## 维护

每次增量资料保留文件名、工作表、行号和文件校验值。对实际使用的题录先在本次 run 记录核对结果；经维护者确认后再更新共享目录。保留旧版本与更正的关联，不直接删除旧版。补充优先级：有标识冲突的记录、无题名线索、无直接链接、未选出候选的学科主题、指南更新/替代关系。不要复制商业数据库全文或将原表摘要汇总当推荐正文。
