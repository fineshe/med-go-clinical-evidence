# 指南机构与二次证据入口

先按疾病、人群、地区定位机构，机构名称不代替单份指南的方法/时效评价。这里只列常用入口，不声称覆盖所有学科。具体指南优先从 [学科目录](guidelines/README.md) 的 DOI、PMID 或原表链接定位，再查机构更新。

| 场景 | 入口 | 本包记录的用途 |
|---|---|---|
| 中国临床诊疗规范/卫生政策 | [国家卫生健康委](https://www.nhc.gov.cn/) | 查正式文件与版本；政策和证据推荐分开 |
| 中国专业学会/期刊指南 | [中华医学会](https://www.cma.org.cn/)、[中华医学期刊网](https://www.yiigle.com/) | 发布机构核实、原文定位；中文覆盖另查 SinoMed/知网/万方 |
| 国际/全球公共卫生 | [WHO Guidelines](https://www.who.int/publications/who-guidelines) | 全球临床及公共卫生推荐；核对本地可迁移性 |
| 英国跨专科 | [NICE Guidance](https://www.nice.org.uk/guidance) | 按 topic/编号查现行、更新和被替代文档；不要依据原表手填编号直接拼 URL |
| 英国妇产科 | [RCOG Green-top](https://www.rcog.org.uk/guidance/browse-all-guidance/green-top-guidelines/) | 区分现行和 archived 指南 |
| 其他专业机构 | 题录内列出的 ACOG、SMFM、SOGC、ISUOG、FIGO、KDIGO、ESC、AHA/ACC、NCCN 等 | 仅对本次有关机构查官方入口；学会/期刊名与原文署名核对 |
| 系统综述 | [Cochrane Library](https://www.cochranelibrary.com/)、[Epistemonikos](https://www.epistemonikos.org/) | 指南之后定位系统综述/Meta，核对检索截止与方法 |
| 中文二次研究 | [SinoMed](https://www.sinomed.ac.cn/)、[知网](https://www.cnki.net/)、[万方医学网](https://med.wanfangdata.com.cn/) | 补中文综述及原文线索，语法见数据库手册 |
| 更新/原始研究及身份核对 | [PubMed](https://pubmed.ncbi.nlm.nih.gov/) | NCBI 旗下文献数据库；不把 PubMed 的所有文献当指南或全文 |

2026-10-19本次打开并读取 WHO、RCOG 官方页面；NICE 单页工具访问失败。其他入口沿用资源目录/机构定位信息，本次没有逐一登录、执行检索或验证订阅权限。入口可用性与具体指南有效性必须分别记录。
