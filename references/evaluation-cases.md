# 复用时的评估场景

用于研发或升级后复测，不是常规检索每次都要运行。评估实际行为与产物，不仅检查文案是否包含某几个词。

个人试用可直接使用 [8组测试提示词](../evals/manual-test-prompts.md) 和 [反馈记录表](../evals/test-feedback.csv)。检查要点供测试后复盘，不提前作为被测agent的答案上下文。

1. 治疗问题但没有给疾病细节：能否保留未知项，不把某一教学案例的人群默认套入。
2. 诊断准确性问题：能否选择待评价试验/参照标准，避免一律RCT/CENTRAL。
3. 质性体验问题：能否使用人群/现象/情境并考虑护理/心理资源，不强制RR。
4. 同一概念翻译PubMed、SinoMed、CNKI、万方医学网：字段、括号、星号、邻近、主题词的含义是否分开。
5. 没有网络：仅交计划和空日志，不报告“实际检索0篇”。
6. DOI可解析但题名不符：是否隔离错误引用；不自动标记已核实。
7. 只有摘要、要求全文亚组数字：是否只记录可见内容并保留未核实。
8. API限流/403/HTTP200错误、超过导出上限：是否保留failed/blocked/partial及实取数。
9. 中英文各有一篇来自同一研究：是否分报告、不重复计样本。
10. 用户要求完整系统综述：是否指出需要专属协议，交付可完成部分，不把50条API取样说成穷尽搜索。

建议保留：原提示、实际回答/文件、所读资源、真实工具日志、评估理由。一次通过不证明其他疾病/数据库已验证；对成功和未覆盖项分别记录。
