# 执行记录与证据核查

## 逐库检索记录

使用 [CSV](../assets/search-log-template.csv)。一条实际查询一行；迭代查询保留版本而非覆盖。

状态：
- planned：仅设计；未执行。
- completed：这条查询按计划执行并完成计划内导出。仍需另报是否取全全部命中。
- partial：已执行但截断、只取前N条、部分导出失败或部分页面不可用。
- blocked：实际访问尝试被权限、验证码或网络阻挡。
- not_selected：未选择，说明理由。
- failed：接口/语法/响应异常，不能解释为无证据。

同时保存原始结果/历史、报告总数、已取条数、去重条数、数据库的查询解释及警告。自动扩展、MeSH/Emtree爆炸、语言、日期字段、排序都影响复现。已执行但取全未知时写unknown；不要猜总数。HTTP200仍可能携带错误。

## 四个维度，不能互相代替

| 维度 | 记录内容与状态 |
|---|---|
| 身份 identity | 题名、作者、年份、期刊、DOI/PMID/注册号与原始记录是否一致；matched / mismatch / unresolved |
| 获取 retrieval | not_retrieved / metadata / abstract / full_text / full_text_and_supplement；保存版本、URL、访问日期 |
| 主张 claim | 主张原文、结局、时间、分母/分析集、比较方向、数值及区间、原文页/表/段定位；supported_at_read_level / contradicted / unresolved / not_assessed |
| 人工复核 human_review | not_requested / pending / reviewed；pending表示已提出或分派复核且尚未完成，不能因“应该复核”就假称已进入人工流程；reviewed只能由实际复核人及日期、意见支持 |

脚本抓到题录后，身份初始为unresolved，主张初始为not_assessed，不能自动盖“核实完成”。已提出具体待核主张但材料不足时，主张记unresolved。仅验证DOI存在还需要身份匹配；仅有摘要也可以准确记录摘要里写出的数字，但获取层级仍是abstract。

获取层级只记录本次实际获得并读取的内容。如果用户只是说“有摘要/全文”，实际内容尚未提供或打开，retrieval写not_retrieved，另在claimed_available_level记录来件描述，不能把转述当成本次已读。是否请求人工复核也按真实行动记录。

每条关键主张都单独核查。推荐用 [主张模板](../assets/claim-template.csv)。查不到全文不判文献虚假；DOI题名不符应隔离该错误引用，回到题名/作者/PMID定位真正文献，不“修正”成看似合理的参考文献。

## 研究与报告

为同一研究建立 study_id，为每篇报告建立 report_id。注册号是强关联线索但不是唯一依据；无注册号时核对作者、地点、时间、样本、干预等。主报告、随访、亚组、协议、更正、撤稿关系单列。保留中文/英文发表可能重叠的判断与理由；去重不删除有独立信息的随访。

## 按问题提取

- 治疗：绝对与相对效应、基线风险、伤害、随访；替代结局和患者重要结局分开。
- 诊断：阈值、参照标准、患者谱、敏感度/特异度及区间；诊断准确不自动证明改善健康。
- 预后：起点/时间、校准/区分度、内部与外部验证；开发表现不能代替外部验证。
- 病因：暴露时序、调整变量、效应及混杂；观察关联不能直接归因。
- 患病率：抽样框、代表性、病例定义、分母、时段、权重。
- 质性：样本/情境、方法、主题、支持材料；不强制转成RR或显著性。
- 经济/实施：视角、资源、货币/价格年份、比较、环境与不确定性。

任何精确计算要保留输入和计算方法，避免从四舍五入百分比倒推精确人数。无数据就留空并注明原因。禁止用论文摘要的积极措辞替代对实际结局的核对。

综述可指向原始研究，但不能把综述和其纳入试验当作相互独立重复证据。不得凭期刊名、被引量或研究设计单独宣布“高质量”。未做正式评价就标为“初步方法学评议”。

临床采用或正式科研交付前，将关键结论、未核实内容和适用性提交负责人复核；不让agent给自己编造审阅者。教学演示与检索计划无需为此阻断。
