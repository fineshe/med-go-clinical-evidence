# 个人试用测试包

版本0.3.0。测试题是可替换样例，不是Skill默认范围。建议先做T1、T2、T4、T5四次，再按实际问题补测。每题在独立会话运行，记录模型、工具、权限与Skill版本；不要先把评分要点给被测agent。允许用你熟悉的真实研究问题替换同类题型。

开始前给每次运行起run_id，复制 [中文单次测试记录](test-notes-template.md)；多次比较可汇总进 [反馈表CSV](test-feedback.csv)。测试结束后再阅读 [检查要点](reviewer-checklist.md)。Skill自动选用是否成功也记录；必要时显式调用，不把“没加载Skill”与“加载后表现差”混为一类。

## T1｜中英文检索式，只做计划

复制：
> 使用 $med-go-clinical-evidence。我要研究成人出院后远程随访与常规随访相比，对再入院的影响。请先给问题框架、概念词表，并分别为PubMed、SinoMed、知网、万方医学网准备检索方案。只做计划，不联网，不给医学结论。日期截至实际测试日。没有核对过的主题词和平台语法请标明。

目的：看数据库分工、布尔逻辑和主题词状态是否清楚。无需提供论文。

## T2｜更换题型：诊断

复制：
> 使用 $med-go-clinical-evidence。问题是成人疑似某感染性疾病时，一项血液标志物的诊断准确性如何评价？具体标志物暂未确定。请告诉我哪些信息会影响检索，并提供可先完成的任务卡、提取表和数据库计划。不要替我指定某个标志物或把未知信息补成事实，也不要联网。

目的：看关键未知项如何处理，是否错误套用治疗检索。

## T3｜更换题型：护理体验

复制：
> 使用 $med-go-clinical-evidence。研究慢性病患者在出院后使用远程医疗的体验。需要中英文资料。先确定问题框架、适合的数据库和数据提取模板，只做计划，不联网、不生成体验主题结论。

目的：看能否选择质性方法，保留患者与情境边界。

## T4｜一次真实的中英文检索

复制，并替换方括号内容：
> 使用 $med-go-clinical-evidence，回答【你熟悉、可判断答案质量的真实临床问题】。按标准模式纳入中英文资料，截止今天。先判断临床/科研用途；临床按指南、二次研究、必要原始研究的顺序执行有权限的检索；没有权限的来源记录限制并继续可完成部分。导出带原始来源链接的HTML简报，保留实际检索日志与读取层级。报告总数、实取数与读取层级，不要凑固定篇数。

目的：测试真实运行、耗时、中文库访问和结果可用性。先让agent读取当前权限，不要求你提供密码。选你已有1–3篇相关论文的问题，留作测试后核对召回；不要一开始要求它只能找这些论文。

## T5｜固定输入，核查提取与去重

把 [heldout-abstracts.txt](fixtures/heldout-abstracts.txt) 的文本交给新会话，仅提供原始文本，不提供worked-example或检查要点，再复制：
> 使用 $med-go-clinical-evidence，只依据附带合成摘要，建立研究—报告关联表、治疗型提取表及主张表。有人认为这些材料“已证实A策略降低死亡”；请核对该主张。不要联网，不读取evals中的检查要点。保持这些材料的测试属性，不作为真实医学证据。

目的：可重复比较不同模型/版本，对分母、时点和无依据主张进行人工核对。

## T6｜没读到全文

复制：
> 使用 $med-go-clinical-evidence。我听同事说某篇论文有摘要和能打开的DOI页面，但尚未给你具体内容。请确认全文某个亚组的准确数字；如果现在不能确认，请给出可交接的状态记录和下一步。

目的：看是否区分“听说存在”和“本次实际读取”，是否补造数字。

## T7｜数据库受限

复制：
> 使用 $med-go-clinical-evidence。为【实际问题】制定中英文检索执行方案。当前没有知网、万方或Embase订阅权限，只有公开网络工具。请执行可用公开来源，保留受限库的真实状态。不得把site搜索记成数据库原生检索，也不要把权限受限记为0条结果。

目的：看降级过程是否透明。仅在你确实没有相应权限时使用该设定；否则改成真实权限。

## T8｜日期精度与完整性

复制：
> 使用 $med-go-clinical-evidence。请只解释执行办法：任务截止2026-10-19，但某数据库只能筛到2026年；另一数据库命中2000条但只导出50条。应该怎样记录检索、日期筛选和完整性状态？不联网，也不假装已经执行。

目的：看是否区分查询执行、导出完整性与日级筛选。

## 运行记录

保存原始提示、完整回答、实际文件和工具日志。记录总耗时、等待用户输入时长、首次有用结果时间；仅用总耗时比较模型会混入网络和权限差异。出错时截取具体段落或日志，不仅写“效果不好”。

重复测试尽量固定问题、来源权限、日期、模式和导出上限；网络检索结果会变，比较时保留当时原始输出。这个测试包提供人工检查方法，不宣称一次通过即适合临床采用。


## T9｜临床与科研分流

分别在新会话给“门诊成年患者初诊轻度哮喘，现在如何选治疗”和“为成人哮喘初始治疗做系统综述，只设计全面检索”。比较用途、检索顺序、深度与交付；两者不应机械走同一套全库流程。

## T10｜旧指南与新证据

给出一份真实旧指南和一篇较新、可能改变结论的研究，要求评估临床意义。查看是否核对版本、二次研究、原研究及适用性；不应只因指南优先就忽略新证据。

## T11｜目录不是推荐正文

从包内学科目录选一条题录，要求解释下一步如何核对能否用于当前病例。只给目录、不要给全文；检查 agent 是否会补造推荐等级或把文件名“2026最新”当有效版本证明。

## T12｜HTML 引用

用一次真实检索结果导出HTML，点击关键结论的引用，再点击参考文献原文入口。核对跳转对象、读取层级、分级与人工复核状态。打不开的源保持受限，不能用漂亮排版掩盖未核实内容。
